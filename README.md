# Luxury Hotel Booking

**Description:** Responsive luxury hotel booking website built with HTML, CSS and JavaScript. Features a sunset hero, room cards with prices and ratings, a date-validated availability checker, mobile menu and contact footer. Works on phones, tablets and desktops. No dependencies.

## Files
- `index.html` – page structure and inline SVG artwork
- `style.css` – responsive styles (mobile, tablet, desktop)
- `script.js` – menu, ratings, date validation, room booking

## Run locally (PowerShell)
```powershell
cd "C:\Users\-admin\Desktop\calendar"
python -m http.server 8000
```
Open http://localhost:8000 in your browser. Stop the server with `Ctrl + C`.

## Notes
- Photos live in `images/` (hero.jpg, standard.jpg, deluxe.jpg, suite.jpg). Replace them with higher-resolution photos using the same names for sharper results.
- Inter font loads from Google Fonts; a system font is used offline.
